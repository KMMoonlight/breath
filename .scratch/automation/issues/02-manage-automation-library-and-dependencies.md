# 管理自动化清单与依赖状态

Status: ready-for-agent

## Parent

[Breath 自动化](../spec.md)

## What to build

把第一条手动 Automation 扩展为完整的已保存自动化管理体验。用户可以在高密度列表与详情中搜索、选择、编辑、启停和删除自动化；Breath 稳定保留重复名称和创建顺序，并在 Workspace 或 Agent 不可用时暂停而不是丢失配置。

本切片覆盖 PRD User Stories 7–12、19–22、27–43、141–143。排队运行的编辑与禁用行为由后续并发切片补齐，活动运行的终止行为由运行生命周期切片补齐。

## Acceptance criteria

- [ ] 宽窗口使用自动化列表与详情双栏，窄窗口提供可读的独立详情呈现；选择自动化不会创建或选择 Work Session
- [ ] 列表按创建时间从新到旧稳定排列，运行和编辑不改变顺序；相同创建时间使用内部 ID 稳定排序
- [ ] 自动化名称允许重复，内部 ID 始终不展示但可靠关联配置和详情
- [ ] 搜索同时匹配名称、Prompt 和 Workspace；无结果状态可以一键清除搜索
- [ ] 列表行展示名称、单行 Prompt、Agent、Workspace、触发摘要、下次时间、最近状态与时间、启用开关和立即运行
- [ ] 用户可以编辑名称、Workspace、Prompt、Agent、触发规则和最大运行时长；活动运行继续使用启动时配置快照，修改只影响后续运行
- [ ] 用户禁用自动化后计划停止，但依赖可用时仍可立即运行；手动运行不改变禁用状态
- [ ] Workspace 路径不可用、Workspace 被移除、Agent 被卸载或版本不兼容时自动化进入依赖暂停并显示具体原因，任何触发均不可用
- [ ] Workspace 被移除时自动化保留最后可展示摘要而不级联删除，用户必须显式改选 Workspace
- [ ] 依赖恢复不会自动重新启用，用户显式启用后才恢复后续触发
- [ ] 删除需要确认，并永久删除当前没有活动运行的自动化及其现有结果；项目目录、Agent 配置和其他自动化不受影响
- [ ] 使用公开用例与临时真实数据库覆盖重复名称、稳定排序、搜索、编辑快照、启停、依赖暂停、Workspace 删除和重启恢复
- [ ] App Shell 验证覆盖双栏/窄窗口、搜索空状态、行摘要、编辑表单、禁用原因、删除确认、键盘与 VoiceOver 语义
