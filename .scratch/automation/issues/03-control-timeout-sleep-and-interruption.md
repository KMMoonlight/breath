# 安全地取消、超时和中断自动化运行

Status: ready-for-agent

## Parent

[Breath 自动化](../spec.md)

## What to build

完成 Automation Run 的安全生命周期：用户可以取消活动运行，最大运行时长能够终止失控 Agent，运行期间只阻止空闲系统睡眠，应用退出和崩溃会把未完成状态收敛为明确结果且不留下进程或临时目录。

本切片覆盖 PRD User Stories 24、31、40–43、115–125，并使删除活动自动化、应用退出确认和启动恢复具备完整端到端行为。

## Acceptance criteria

- [ ] 运行详情在活动期间提供取消操作；取消会终止 Agent 完整进程树、销毁临时目录并标记“已取消”
- [ ] 取消不保存流式片段或部分最终回答，也不修改 Workspace
- [ ] 每个自动化使用自己的最大运行时长，默认 60 分钟；超过有效时长后终止进程树并标记“已超时”
- [ ] 运行中先请求正常终止，短暂宽限后可强制结束；只有确认子进程退出后才完成清理
- [ ] 活动运行持有防空闲系统睡眠断言，不阻止显示器休眠和用户主动睡眠，排队或已完成运行不持有断言
- [ ] 用户主动睡眠后 Agent 由系统暂停并在唤醒后继续，最大运行时长不累计睡眠时段
- [ ] 用户禁用自动化不会隐式终止活动运行；删除活动自动化经过确认后终止运行、清理临时数据并删除配置
- [ ] 应用存在活动运行时退出需要确认；取消退出保持运行，确认退出把活动运行标记“已中断”并完成进程与临时目录清理
- [ ] 应用异常终止后重新启动会把残留运行中记录修复为“已中断”，清理可识别临时目录，不自动恢复或重跑
- [ ] 超时、取消、中断、删除和退出失败都返回清理后的可操作错误，不包含凭据、完整命令行或环境变量
- [ ] 公开用例测试使用虚拟时钟、电源断言和记录型 Runner 覆盖取消、超时、睡眠、唤醒、退出确认、崩溃恢复和删除活动自动化
- [ ] 真实进程契约测试验证 Agent 子进程树不会成为孤儿，沙盒与 Workspace 只读边界在所有终止路径中保持
- [ ] App Shell 验证覆盖运行中取消、退出确认、终态显示以及键盘和 VoiceOver 状态语义
