# 展示最近五次结果与未读角标

Status: ready-for-agent

## Parent

[Breath 自动化](../spec.md)

## What to build

交付完整的 Automation Run 结果阅读体验。每个自动化只保留最近五次运行，以统一状态和最小元数据展示；需要用户查看的结束结果汇总为活动栏数字角标，只有打开具体记录才将其标为已查看。

本切片覆盖 PRD User Stories 126–140、144–152，并为后续队列和调度产生的“已跳过”“已错过”记录建立统一展示契约。

## Acceptance criteria

- [ ] 运行状态模型只包含已排队、运行中、成功、失败、已超时、已取消、已中断、已跳过和已错过，并只允许定义好的公开转换
- [ ] 成功要求正常退出且最终回答非空；失败、超时和中断在没有最终回答时只保存清理后的短错误摘要
- [ ] 每条记录保存触发来源、排队/开始/结束时间、有效时长、Agent、可靠可知的模型、可解析的起始 Git Commit、实时 Workspace 标记和已查看状态
- [ ] 最终输出按 UTF-8 最多持久化 256 KiB，超限时在上限内保留开头和结尾、插入截断标记并记录截断状态
- [ ] 每个自动化最多保留最近五条记录；第六条产生时淘汰最旧终态记录，当前未终结记录不会为执行上限而被删除
- [ ] 详情列出最近五次运行，点击具体记录后使用完整 GFM 块级布局展示 Markdown 最终回答或清理后的错误摘要；原始 HTML 不执行、远程图片不自动请求
- [ ] 复制操作复制原始文本；页面不提供“查看原文”、编辑、Diff、Artifact、导出或应用到 Workspace
- [ ] 成功、失败、已超时和已中断的新记录默认未查看并计入角标；已取消、已跳过和已错过不计入，非终态不计入
- [ ] 只有点击具体运行记录才将该记录标记已查看；打开自动化详情、切换页面和重启应用不会批量清除
- [ ] 活动栏显示持久化的总未读数量，超过 99 显示 `99+`；VoiceOver 名称包含未读数
- [ ] 所有状态都不发送 macOS 系统通知、声音、邮件或其他外部完成通知
- [ ] 公开用例与真实临时数据库测试覆盖状态判定、输出截断、最近五条淘汰、删除清理、单条已读、重启保留和角标筛选
- [ ] App Shell 验证覆盖历史选择、标题、段落、嵌套列表、任务项、引用、代码、表格、行内样式与链接等 Markdown 结果、复制、角标、`99+`、不误清未读及可访问性语义
