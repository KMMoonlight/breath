# 从 ZIP 安装一个 Skill 到一个 Agent

Status: implemented

## Parent

[Breath 全局 Skills 管理](../spec.md)

## What to build

交付首条完整安装路径：用户从原生文件选择器选择包含一个候选 Skill 的 ZIP，审阅候选内容和目标后，将完整实体目录原子安装到一个明确选择的 Agent 全局目录。此切片只收窄候选和目标数量，不省略安全校验、强制预览或回滚保证。

本切片覆盖 PRD User Stories 43、46、65–66、68–73、81–84、90–92、94、96、124–125。

## Acceptance criteria

- [x] “安装 Skill…”向导提供 ZIP 来源并使用原生文件选择器；关闭或取消任一步骤都不会写入 Agent 目录
- [x] 首条 ZIP 路径可以解析一个候选 Skill，并对缺少 `SKILL.md`、`name` 或 `description` 返回不可安装错误
- [x] 名称格式或目录名偏差作为可继续警告展示，不擅自修改 Skill 名称、说明或目录名
- [x] ZIP 解析在受控临时目录中执行，限制压缩包大小、展开总量、文件数、目录深度和候选数，并拒绝绝对路径、`..` 越界、危险链接、设备文件及其他特殊文件
- [x] 候选中的脚本、Hook 和构建文件只作为文件保留；解析、预览和安装过程中不会执行任何来源代码
- [x] 目标选择默认全部不选、不记忆上次选择，只允许选择已安装、兼容且实际 Skill 目录可可靠解析的 Agent；本切片要求用户明确选择一个目标
- [x] 写入前预览展示 ZIP 来源、名称、说明、完整 `SKILL.md`、文件清单、警告、声明信息、Skill 安装目标和真实安装路径
- [x] 安装将候选的完整文件树暂存并原子提交为 Skill 安装目标目录中的实体目录，不创建 Breath 中心副本、分发符号链接、sidecar 或扩展元数据
- [x] 单目标失败不会留下不完整目录；成功结果立即刷新实际列表并提示可能需要新建或重启 Agent 会话
- [x] ZIP 安装不提供更新能力，也不会重启 Agent、停止终端、改变工作会话或注入现有对话
- [x] 使用真实 ZIP 和临时 Agent 根目录覆盖合法 Skill、必要字段缺失、格式警告、资源文件、资源上限、损坏压缩包、路径攻击以及脚本未执行 sentinel
