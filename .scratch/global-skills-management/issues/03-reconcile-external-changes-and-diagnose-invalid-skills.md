# 同步外部变更并诊断异常 Skill

Status: implemented

## Parent

[Breath 全局 Skills 管理](../spec.md)

## What to build

让 Skills 页面持续反映 Agent 目录的真实状态，包括其他工具创建、修改或删除的 Skill、外部符号链接以及无法解析的目录。异常项目进入只读诊断区域，不混入正常 Skill，也不提供侵入式删除操作。

本切片覆盖 PRD User Stories 25、38–42、128。

## Acceptance criteria

- [x] 页面打开期间监听所有已解析的 Agent Skill 目录，外部创建、修改和删除经过节流后触发完整对账并更新聚合快照
- [x] 应用重新激活和用户手动刷新都会执行完整扫描，从而修正遗漏或合并过的文件事件
- [x] 指向外部目录的合法符号链接作为正常 Skill 展示，并明确标示其链接性质、链接路径和解析后的目标位置
- [x] 扫描防止链接循环、越界遍历和失控递归；断链、不可读路径、循环链接及解析失败不会阻塞其他 Agent 或 Skill
- [x] 缺少必要内容或无法解析的现有目录进入单独的“无法识别的项目”区域，显示可操作原因且不计入正常 Skill 数量
- [x] 无法识别的项目只能刷新、复制已清理的诊断信息或在 Finder 中定位，首版不提供直接删除
- [x] 外部变化与 Breath 正在读取其他 Agent 目录并发发生时，各目录独立对账，最终页面以最新实际文件状态为准
- [x] 诊断错误不包含环境变量、凭据、敏感 URL 查询参数或无关用户路径
- [x] 使用临时真实目录覆盖快速连续事件、外部创建/修改/删除、普通链接、共享目标、断链、循环链接、权限错误和应用重新激活
