# 批量安装 Skills 并处理同名覆盖

Status: implemented

## Parent

[Breath 全局 Skills 管理](../spec.md)

## What to build

把 ZIP 安装扩展为多个候选 Skill 和多个目标 Agent 的安全批处理。每个“候选 Skill × Agent”都是独立结果单元；同一个 Agent 已有同名 Skill 时，根据实际内容让用户选择跳过或覆盖，默认跳过，其他可安装项继续执行。

本切片覆盖 PRD User Stories 44–45、67、74–80、85–89、127–129。

## Acceptance criteria

- [x] ZIP 可发现一个或多个候选 Skill；用户明确多选候选，多个候选共享一次目标 Agent 选择和预览流程
- [x] 返回上一步会保留已选来源、候选和目标，取消流程不会产生任何文件或安装记录
- [x] 强制预览逐个展示所选候选的来源、说明、文件、安全警告、目标、真实路径及每个目标的写入影响
- [x] 同一 Agent 已有同名同内容 Skill 时显示“已安装”并作为 no-op，不重复写入
- [x] 同一 Agent 已有同名不同内容 Skill 时展示现有与新 `description` 及文件变化，并允许按目标选择覆盖或跳过；默认始终为跳过
- [x] 同名处理不会自动改名，用户可以只跳过部分 Agent 而让其他目标继续安装
- [x] 每个目标获得完整独立实体副本，成功与失败按“Skill × Agent”分别报告；一个目标失败不会回滚其他成功目标
- [x] 单目标覆盖先建立可恢复的临时副本，再原子替换；暂存、替换或提交失败时原 Skill 仍完整可用
- [x] 实际写入前重新检查目录、同名占用和内容摘要；预览后发生外部变化时要求重新确认或安全失败，不覆盖新状态
- [x] 同一 Agent 全局目录内的安装、更新和卸载协调入口串行执行，不同 Agent 目录可以并行处理
- [x] 结果页面分别列出成功、已安装、已跳过和失败项目，错误提供简短可操作原因及经过清理的可复制详情
- [x] 使用真实 ZIP 和临时多 Agent 目录覆盖多候选、多目标、no-op、默认跳过、显式覆盖、无权限目标、原子回滚、部分成功和写入前竞态
