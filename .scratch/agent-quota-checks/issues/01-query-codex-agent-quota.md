# 打通 Codex Agent 额度检查

Status: implemented

## Parent

[Agent 额度检查](../spec.md)

## What to build

交付第一条完整 Agent 额度路径：用户从活动栏进入额度页面，只看到已安装的受支持 Agent，并能查看和刷新 Codex 当前登录身份的官方额度。该切片同时建立后续 Agent 共用的查询、安全、状态与展示契约。

## Acceptance criteria

- [x] 活动栏顶部主功能组在 Skills 后提供“额度”入口，点击后在主内容区打开额度页面，设置仍固定在底部
- [x] 页面只为当前已安装且受支持的 Agent 创建卡片；没有卡片时主内容区留空，不显示空状态或操作
- [x] 每张卡片具备查询中、可用、未登录、不支持查询和查询失败状态，并提供独立刷新；页面在有卡片时提供全部刷新
- [x] Codex 优先通过合规的官方网络接口查询，接口失效时在同一次刷新中使用官方 CLI 或协议兜底
- [x] Codex 的全部官方额度窗口分别展示，百分比保留“已使用/剩余”语义，非百分比保留原始数值和单位
- [x] 官方提供的账号身份只以遮罩形式展示；未提供时不额外读取或推断
- [x] 凭据只存在于单次请求内存中，只发送到获授权的服务商官方 HTTPS 域名，不进入持久化、日志、错误或界面
- [x] 打开页面自动查询一次，结果只保留在当前运行内；失败直接替换旧结果
- [x] 全部刷新并发执行，单卡完成即更新；每个 Agent 的完整查询链路独立 15 秒超时
- [x] 精确重置时间按本机时区格式化，并通过与相关标题相邻的信息图标在 300ms 后悬浮展示
- [x] 页面和卡片具备中英文、本地化、键盘和 VoiceOver 语义，状态不只依赖颜色
- [x] 公共查询服务、安装过滤和应用外壳入口均有行为测试，测试凭据不会出现在失败文本或记录中

## Blocked by
