# 正常退出并按需恢复工作会话

Status: ready-for-agent

## Parent

[Breath v1 PRD](../spec.md)

## What to build

交付正常退出的安全协调和冷启动按需实例化。`⌘Q` 先确认并以事务方式保存结构、最后选择和恢复标记，再停止全部终端进程；重新启动只立即处理退出前选中的工作会话。

## Acceptance criteria

- [ ] `⌘Q` 总是确认，取消不会改变进程
- [ ] 确认时保存先于停止，全部终端进程随后退出
- [ ] 冷启动只实例化最后选中的工作会话，其他会话首次选择时才实例化
- [ ] 已实例化会话切走后继续运行
- [ ] 最后选择无效时保持空白，不自动启动其他会话
- [ ] 不持久化终端滚动历史，崩溃不宣称干净恢复保证
