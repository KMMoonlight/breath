# 归档、恢复和永久删除工作会话

Status: ready-for-agent

## Parent

[Breath v1 PRD](../spec.md)

## What to build

交付工作会话的完整归档生命周期。归档由用户明确触发并停止全部窗格，只在设置窗口的已归档管理页出现；恢复只放回活跃列表，永久删除只清理 Breath 元数据。

## Acceptance criteria

- [ ] 回合或命令结束不会自动归档，只有归档按钮触发
- [ ] 活动进程归档前确认，确认后停止该工作会话全部终端
- [ ] 归档项从主会话树消失且只在设置的已归档页面出现
- [ ] 恢复保持设置窗口与当前选择不变，也不立即创建进程
- [ ] 后来选中恢复项时按保存布局实例化
- [ ] 永久删除二次确认且不删除项目文件或 Agent CLI 数据
