# 交互编辑代码块、表格和任务列表

Status: implemented

## Parent

[Breath 全局 Markdown 笔记库与笔记 Agent 抽屉](../spec.md)

## What to build

在源码保真文档模型上交付程序员高频的结构化编辑体验：代码围栏按语言高亮并可复制，表格可以用键盘和上下文菜单编辑，任务列表复选框可以直接切换。所有交互都只修改必要 Markdown 区间并遵循显式保存。

本切片覆盖 PRD User Stories 63、86–92、98。

## Acceptance criteria

- [ ] 代码围栏按声明语言使用离线打包的语法高亮，未知语言安全降级为普通代码
- [ ] 代码块悬停显示复制操作，复制内容是原始代码正文，不包含围栏、行号或展示性字符
- [ ] 代码块行号默认关闭，展示层支持消费 Notes 偏好且永不改写 Markdown
- [ ] GFM 表格在所见即所得模式中保持行列结构、对齐和源码内容可编辑
- [ ] 表格单元格中 `Tab` 移动到下一格，在最后一格按需新增一行；`Shift-Tab` 按反向顺序移动
- [ ] 表格右键菜单可以添加或删除行列并设置对齐，操作结果保存为标准 GFM 表格
- [ ] 任务列表复选框可以直接点击，点击后更新对应 Markdown 标记、进入撤销历史并显示 `*`
- [ ] 结构操作与源码模式编辑使用同一保存基线；撤销到基线时 `*` 消失
- [ ] 代码块、表格和任务列表中的未知格式或非标准源码在未修改区域保持字节一致
- [ ] 结构化编辑不引入常驻格式工具栏、表格工具栏或通用富文本菜单
- [ ] 复制、表格导航和复选框具备键盘等价操作与明确 VoiceOver 语义
- [ ] 固定语料覆盖不同围栏字符、嵌套列表表格、转义管道、空单元格、对齐、任务嵌套和未知语言
- [ ] 真实 WebKit 契约验证每种交互的源码最小差异、撤销重做、脏状态、保存和标签切换
- [ ] App Shell 验证覆盖复制反馈、表格上下文菜单、焦点移动、代码行号消费和可访问状态
