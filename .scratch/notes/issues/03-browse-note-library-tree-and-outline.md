# 浏览 Note Library 文件树与文档大纲

Status: implemented

## Parent

[Breath 全局 Markdown 笔记库与笔记 Agent 抽屉](../spec.md)

## What to build

交付完整的只读浏览路径：用户可以按文件夹层级浏览 Note Library，在文件与当前 Markdown 大纲之间切换，调整侧边栏并按名称或时间排序、过滤文件；不同文件类型进入正确的编辑、预览或系统打开行为。

本切片覆盖 PRD User Stories 13–20、42–46。

## Acceptance criteria

- [ ] 侧边栏按真实文件夹层级展示文件夹、Markdown、文本和普通附件，默认文件夹优先并按自然名称排序
- [ ] 点文件和符号链接完全不展示、不遍历；扫描和打开阶段都验证规范化路径没有越过 Note Library
- [ ] 用户可以按名称、修改时间或创建时间排序，并分别选择升序或降序
- [ ] 文件名过滤对当前文件树即时生效，匹配文件保留必要父目录上下文，不执行正文搜索
- [ ] 侧边栏可以在“文件”和“大纲”之间切换；大纲根据当前 Markdown 标题层级生成并可定位对应标题
- [ ] 用户可以拖动侧边栏边缘调整宽度，宽度受合理最小值和主编辑区约束并跨重启恢复
- [ ] `.txt` 在 Note Tab 中以纯文本源码状态打开，不启用 Markdown 渲染或富文本转换
- [ ] 图片在 Breath 中预览并保持自然宽高比；PDF 和其他附件交给 macOS 默认应用打开
- [ ] Note Library 外部的 Markdown 不进入 Breath 可编辑标签；系统打开后，用户仍可通过拖入或复制把文件纳入库
- [ ] 文件类型识别以真实扩展名为准，扩展名在树和标签相关界面中始终可见
- [ ] 文件树状态在目录事件后收敛到真实磁盘快照，不依赖事件恰好一一对应文件操作
- [ ] 使用包含深层目录、自然排序名称、点文件、符号链接和各类附件的临时目录验证扫描、过滤、排序、大纲及打开策略
- [ ] App Shell 验证覆盖宽窄窗口、文件/大纲切换、侧边栏调整、图片预览、系统打开、键盘导航和 VoiceOver 层级语义
