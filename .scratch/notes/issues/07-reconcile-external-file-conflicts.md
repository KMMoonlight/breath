# 处理外部文件变化与编辑冲突

Status: implemented

## Parent

[Breath 全局 Markdown 笔记库与笔记 Agent 抽屉](../spec.md)

## What to build

让 Notes 对 Finder、同步软件、Git 和 Agent CLI 产生的外部文件变化可靠收敛。干净标签自动重载，脏标签进入可比较的冲突状态；外部删除或移动不会丢弃内存缓冲区。Breath 自己产生的原子写入不会被误报成外部冲突。

本切片覆盖 PRD User Stories 112–115、149。

## Acceptance criteria

- [ ] 文件监控合并批量、临时和原子替换事件，并以最终文件系统快照收敛，而不是假定一个事件对应一次用户操作
- [ ] Breath 自己完成的保存和文件操作通过文件身份与内容指纹去重，不触发虚假外部冲突
- [ ] 干净 Note Tab 对外部内容修改自动重载并更新保存基线、编辑画布和大纲
- [ ] 脏 Note Tab 遇到外部修改时保留内存缓冲区并显示冲突横幅，停止任何自动覆盖
- [ ] 冲突操作提供“比较”“用我的版本覆盖”和“重新加载磁盘版本”，每个破坏性选择都明确说明将丢弃哪一份内容
- [ ] “比较”展示当前缓冲区与磁盘版本的只读 Markdown 差异，不提供搜索替换或通用代码编辑器能力
- [ ] 覆盖使用原子写入并只在成功后清除冲突和 `*`；重载磁盘版本会明确丢弃内存修改和恢复快照
- [ ] 外部删除或移动已打开文件时保留内存内容，标签进入不可用状态并允许在 Note Library 内另存为
- [ ] 外部目录变化同步更新文件树、文件过滤和标签路径，不遍历新出现的点文件或符号链接
- [ ] 外部变化接口供 Note Agent 写入复用，不按变更来源建立第二套冲突规则
- [ ] 冲突期间普通 `Cmd-S` 不会静默覆盖新磁盘版本，必须先选择冲突处理策略
- [ ] 使用真实临时目录覆盖直接写入、原子替换、同步临时文件、快速批量事件、外部删除、移动和 Breath 自写去重
- [ ] 可控竞态测试验证保存与外部改写同时发生时不会截断文件、丢失缓冲区或错误清除冲突
- [ ] App Shell 验证覆盖自动重载、冲突横幅、差异视图、另存为、错误状态、键盘和 VoiceOver 语义
