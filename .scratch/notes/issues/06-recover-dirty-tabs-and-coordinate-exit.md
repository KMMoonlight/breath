# 恢复未保存 Note Tab 并协调退出

Status: implemented

## Parent

[Breath 全局 Markdown 笔记库与笔记 Agent 抽屉](../spec.md)

## What to build

为显式保存模型补齐崩溃保护和应用级退出协调：编辑时可以节流写入 Breath 私有恢复快照，但绝不自动覆盖源文件；异常终止后恢复脏标签和 `*`，正常关闭、退出或切换 Note Library 时统一处理所有未保存文档。

本切片覆盖 PRD User Stories 7、77–78、105–111。

## Acceptance criteria

- [ ] 文档编辑后可节流写入私有恢复快照，快照包含文件身份、保存基线指纹和恢复所需数据，但不替代源文件
- [ ] 写恢复快照不会清除 `*`、改变源文件修改时间或被展示成一次保存
- [ ] 应用异常终止后，启动恢复脏标签、顺序、选中项和未保存内容，并继续显示 `*`
- [ ] 若源文件自快照基线后发生变化，恢复标签进入明确冲突状态而不是静默覆盖任一版本
- [ ] 用户成功保存或明确丢弃文档后清除对应恢复快照；保存失败继续保留快照
- [ ] 正常退出 Breath 时汇总全部脏标签并提供“全部保存”“全部不保存”“取消”，取消会中止退出
- [ ] 切换 Note Library 复用同一协调器；取消或保存失败保持原库、原标签和原恢复状态
- [ ] 关闭窗口但应用仍运行时遵循已确认的标签关闭语义，不把窗口关闭误当应用崩溃
- [ ] 恢复标签对应文件缺失或移动时保留缓冲区，并允许在当前 Note Library 内另存为
- [ ] 恢复快照存储使用现有本地数据库安全权限和迁移边界，不创建笔记版本历史或用户可浏览历史
- [ ] 数据库损坏或快照解码失败时隔离坏记录并保留源文件，不阻塞其他干净标签恢复
- [ ] 使用真实临时数据库和 Note Library 覆盖崩溃、正常退出、切库、源文件冲突、保存失败、快照清理和缺失文件另存为
- [ ] 原始数据库检查确认恢复内容只存在于明确的恢复载荷中，且没有产生 Agent 或终端内容
- [ ] App Shell 验证覆盖恢复提示、脏标签、退出汇总、取消退出、另存为、键盘和 VoiceOver 语义
