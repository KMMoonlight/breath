# 管理多个 Note Tab

Status: implemented

## Parent

[Breath 全局 Markdown 笔记库与笔记 Agent 抽屉](../spec.md)

## What to build

把第一条单文档编辑路径扩展为完整 Note Tab 工作流：同时打开多个唯一文件标签、拖动排序、处理溢出和同名消歧，并以 VS Code 风格菜单关闭单个或一组标签。干净标签的顺序和选中项可以跨应用重启恢复。

本切片覆盖 PRD User Stories 99–111、116、126。

## Acceptance criteria

- [ ] 每个规范化文件身份最多对应一个固定 Note Tab，不存在预览标签；再次打开只聚焦已有标签
- [ ] 用户可以拖动标签改变顺序，标签顺序和当前选中项通过公开仓库跨重启恢复
- [ ] 标签超出宽度时支持水平滚动或溢出定位，不压缩到无法识别或遮挡关闭操作
- [ ] 同名文件使用能消除歧义的最短父目录路径，悬停和无障碍描述提供完整路径
- [ ] 标签提供关闭按钮但不响应鼠标中键关闭
- [ ] 标签菜单包含关闭、关闭其他、关闭左侧、关闭右侧和全部关闭，不提供固定、分组或编辑器分屏
- [ ] `Cmd-W` 只关闭当前 Note Tab，不关闭 Breath 窗口或 Work Session
- [ ] 关闭单个脏标签时提供“保存”“不保存”“取消”；保存失败保持标签打开并保留 `*`
- [ ] 批量关闭多个脏标签只显示一次汇总确认，支持“全部保存”“全部不保存”“取消”
- [ ] 批量保存中失败的标签保持打开和选中可达，成功保存的标签按请求关闭
- [ ] 应用重启恢复干净标签、顺序和选中项，不把干净文件正文复制到数据库
- [ ] 恢复时缺失或移动的文件显示不可用标签，允许关闭；若存在可恢复内存内容则由恢复切片提供另存为
- [ ] 快速切换标签时共享 WebView 使用文档身份和版本拒绝迟到响应，不把旧文档状态写入新标签
- [ ] 使用临时真实库和持久化仓库覆盖唯一性、排序、同名、各类批量关闭、部分保存失败和重启恢复
- [ ] App Shell 验证覆盖标签滚动、拖动、菜单、确认对话框、快捷键、焦点恢复和 VoiceOver 名称
