# Agent 额度检查

## 已确认范围

- 活动栏顶部主功能组在 Skills 之后增加“额度”入口，“设置”继续固定在底部；点击后切换主内容区，不打开独立窗口。
- 页面只展示当前已安装且受支持的 Agent CLI；未安装项不创建卡片。
- 没有检测到任何已安装且受支持的 Agent 时，主内容区留空，不显示空状态文字、重新检测按钮或安装引导；重新进入额度页时再次检测。
- 额度数据必须来自服务商官方来源，Breath 不根据本地对话、Token 或费用估算。
- 查询复用 Agent CLI 当前登录身份；Breath 不新增服务商登录或 API Key 输入。
- 查询优先使用服务商官方网络接口：先使用公开 API；没有公开 API 时，可以在服务商未禁止且使用已获授权的前提下调用从官方客户端行为确认的私有接口。找不到可用网络接口时，再使用官方 CLI 或官方协议。
- 已接入的网络接口在运行时失效时，同一次刷新自动尝试合规的官方 CLI 或官方协议兜底；只有该 Agent 的全部合规查询路径均失败后，才进入“查询失败”并展示最终的脱敏原因。
- 官方 CLI 兜底没有结构化输出时，可以解析其面向人的文本，但只能调用官方专用的只读额度或状态命令；不得发送模型提示、消耗模型额度或进入持续交互会话。调用时固定可控的输出语言，解析失败即视为该路径失败；原始 CLI 输出只在请求内存中处理，不写入日志或文件。
- 只有服务商明确允许第三方复用 CLI 凭据时，Breath 才可以只读获取令牌，并仅在一次请求的内存中向对应服务商官方 HTTPS 域名发送。令牌不得持久化、缓存、写入临时文件、记录、展示或发送给第三方。
- 服务商明确禁止第三方复用凭据，或无法确认查询方式已获授权时，不调用私有接口；若也没有合规的官方 CLI 或协议，直接显示“不支持查询”。
- 同一 Agent 的全部官方额度窗口分别展示，保留官方名称、官方额度数值和重置时间，不合并为单一数字。
- 额度数值严格沿用官方计量方式：官方给百分比就展示百分比，给剩余量就展示剩余量；不换算百分比、不推算缺失字段。存在部分有效字段时展示已有数据，缺失字段不补造。
- 打开额度页面时自动查询一次，并提供手动刷新；离开页面后不轮询，应用启动时不后台查询。
- 存在至少一个 Agent 卡片时，页面顶部提供“全部刷新”，每个 Agent 也始终提供独立刷新；Agent 正在查询时禁用它的独立刷新，全部刷新进行期间不对正在查询的 Agent 发起重复请求。没有卡片时不展示这些控件。
- “全部刷新”并发查询所有 Agent，每张卡片完成后立即更新，不等待其他 Agent。每个 Agent 从首选网络接口到 CLI/协议兜底的完整查询链路独立设置 15 秒超时；超时只使该 Agent 进入“查询失败”。
- 额度结果只在当前 Breath 运行期间保留，不写入磁盘；应用重新启动后，首次进入额度页面重新查询。
- 任一次查询失败都直接替换该 Agent 的旧结果并展示失败状态，不保留或展示过期额度。
- 每个已安装 Agent 独立查询并独立呈现结果；单个 Agent 的未登录、不支持或查询失败不阻断其他 Agent。
- 每个已安装 Agent 只能处于“查询中、可用、未登录、不支持查询、查询失败”之一。“查询失败”直接展示经过脱敏的简洁原因，不得包含令牌、账号标识或其他凭据信息。
- 官方额度结果包含当前账号身份时，在 Agent 名称旁展示遮罩后的邮箱或用户名；官方未提供时不额外读取或推断账号。
- 支持多个模型服务商的 Agent 只查询 CLI 当前默认会使用的服务商和登录身份，并在卡片中显示服务商名称；不遍历已配置但未启用的其他 API Key。当前服务商返回多个额度池时仍全部展示。
- 当前 Agent 使用 API Key、BYOK 或按量付费账号时，仍展示官方可提供的余额、消费上限、速率限制或重置信息，并保留官方名称与单位；不要求结果必须是订阅百分比，也不以本地 Token 消耗代替官方额度。
- 官方提供准确重置时间时，转换为用户本机时区，并在页面直接展示相对时间（例如“2 小时后重置”）；精确日期时间放在与相关文字标题相邻的信息图标悬浮提示中，悬浮 300ms 后触发。官方只提供周期时原样展示，不自行计算准确时间。
- 页面按 Agent 注册表中的固定顺序展示，不按剩余额度或状态动态排序，也不提供跨服务商排行或统一进度比较。
- 每个 Agent 使用 360pt 固定宽度的独立卡片，页面按可用空间横向排列并自动换行，卡片不拉伸为整行。卡片顶部展示 Agent 名称、可用时的遮罩账号、状态和独立刷新按钮；下方并列展示全部官方额度窗口，卡片内部宽度不足时自动改为纵向排列。
- 官方提供百分比时使用进度条，并明确保留官方“已使用”或“剩余”语义，不统一反转方向。官方提供剩余量、次数、余额或其他非百分比数值时，只展示原始数值和单位，不伪造成进度条。
- 状态同时使用图标和文字，不能只依赖颜色；颜色只表达正常、警告和失败，不用于比较不同 Agent。
- 警告色只响应服务商明确返回的“接近限制、已达限制”等状态；Breath 不自行设置 80%、20% 等额度阈值。查询失败使用失败色，其余额度数据保持中性。
- 界面不展示查询来源、查询完成时间或内部兜底过程，也不为这些信息增加悬浮提示。
- 额度页保持只读：未登录时不在 Breath 内发起登录，不支持查询时不提供凭据配置入口；安装和登录仍由各 Agent CLI 管理。
