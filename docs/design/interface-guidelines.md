# Breath 界面设计规范

## 流程页面的信息层级

- 流程页面不得使用超大提示标题承载常规说明、来源选择或下一步操作。
- `ContentUnavailableView` 只用于真正没有内容、且当前区域无法继续工作的空状态，不得作为表单、向导或来源选择页的主体布局。
- 向导中的常规标题使用紧凑的 `.headline` 或正文层级，说明文字使用次要颜色，主要操作紧邻相关说明。
- 三个及以上平级来源使用明确命名的 Tab 切换，每个 Tab 只展示该来源需要的输入、说明和结果，不依赖输入内容猜测来源。
- 用户可以在当前页面修正的输入错误、网络错误和来源不可用状态应就近内联展示。Alert 只用于必须中断当前流程的确认或无法继续的意外错误。

以上规则适用于 Skills 安装向导及后续新增的同类分步流程。
