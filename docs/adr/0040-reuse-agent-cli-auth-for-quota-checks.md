# 复用 Agent CLI 登录身份查询额度

额度检查复用各 Agent CLI 当前已登录的身份，不在 Breath 中新增 OAuth 登录或 API Key 输入。查询优先通过服务商官方网络接口完成：先使用公开 API 或官方协议；没有公开 API 时，可以从官方客户端行为确认额度私有接口，并仅在服务商未禁止且这种使用已获授权时调用。找不到可用网络接口时，再使用官方 CLI。只有服务商允许第三方复用 CLI 凭据时，Breath 才可以只读获取现有令牌，并仅在请求内存中调用该服务商的官方 HTTPS 域名；令牌不得写入数据库、配置、缓存或临时文件，不得进入日志、错误、崩溃报告和界面，也不得发送给第三方。服务商明确禁止第三方复用凭据，或 Breath 无法确认这种使用已获授权时，不通过逆向私有接口绕过；若也没有合规的官方 CLI 或协议，则将该 Agent 标记为“不支持查询”。这个选择优先获得无需启动 CLI 的查询体验，同时接受私有接口可能随服务商变化而失效，并保留服务商的认证边界。

当前接入依据必须可在实现测试中审计：Codex 首选官方 `app-server` 的 `account/rateLimits/read` 协议，仅在该协议不可用时尝试官方客户端同源的 ChatGPT 用量接口；Claude 的用量地址、OAuth 请求头与响应字段来自已安装官方 Claude Code 客户端的当前行为；OpenRouter 只调用其公开文档中的 `/api/v1/credits` 和 `/api/v1/key`。所有地址固定为对应服务商 HTTPS 域名，不接受配置覆盖或重定向到第三方。Antigravity CLI 的系统钥匙串凭据不导出或复用；Kimi Code 和 Cursor Agent 在没有确认合规的只读额度路径前保持“不支持查询”。服务商行为或授权边界发生变化时，相关私有路径必须移除或降级为官方 CLI/协议。
