# 默认使用结构化浏览器观察并按需请求截图

浏览器自动化网关的默认观察结果只包含浏览器结构化快照：页面的可访问性结构、稳定元素引用、URL 和标题。Agent 通过这些紧凑数据完成导航、读取和交互，不在每一步接收截图或原始 DOM。只有任务涉及布局、样式、视觉缺陷或最终 UI 验证时，Agent 才显式请求截图；这类视觉验证必须使用具备图形渲染能力的 Chromium。Lightpanda 可以在后续作为非视觉任务的可选引擎，但它的结果不能被标记为视觉验证。这个策略优先降低常规自动化的 token 与执行开销，同时保留对真实视觉结果的验证能力。
