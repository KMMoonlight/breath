# 只在设置页面管理已归档工作会话

归档工作会话从左侧活跃会话树中完全移除，不在工作区下显示“已归档”分组。用户只能在主窗口右侧设置页面的“已归档”管理页查看、恢复或永久删除归档；该页面是会话管理入口，不属于只负责界面样式的应用配置，也不属于只负责终端内部样式的终端配置。恢复只撤销归档并把原工作会话重新加入左侧会话列表，保持设置页面与当前工作会话选择不变，不立即创建 Shell 或 Agent；用户之后选中它时才按保存的布局恢复。永久删除需要二次确认，并且只删除 Breath 元数据，不删除项目文件或 Agent CLI 自身数据。这样保持日常会话树只呈现活跃工作，同时仍保留显式管理入口。
