# 在 Skill 目录之外保存来源记录

Breath 将远程 Skill 的 Agent、路径、来源、引用、Commit 和内容摘要保存在自身 SQLite 数据库中，不向第三方 Skill 目录写入隐藏文件或其他私有元数据。Agent 目录中的实际文件仍是安装状态的事实来源；远程记录只提供可验证的上游关联。路径与 Skill 身份仍一致但内容摘要变化时标记为本地修改并保留上游；记录丢失、路径被其他 Skill 占用或身份无法确认时，Skill 保持可用但降级为来源未知且不能更新。

Breath 可以只读解析受支持的外部工具清单，为指向外部共享内容库的 Agent 符号链接恢复精确来源身份。该信息不等同于 Breath 自己解析并记录的远程上游：Breath 不修改外部清单或共享内容，也不据此声明可更新。ZIP 来源、远程上游和共享来源身份的区别由 ADR 0035 规定。
