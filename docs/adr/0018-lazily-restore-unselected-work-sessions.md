# 只恢复当前选中的工作会话

Breath 在正常退出时保存当时选中的工作会话。下次启动只实例化该工作会话的终端布局：其中退出前仍绑定运行中 Agent 的窗格尝试恢复对话，其他窗格打开新的空 Shell。其余工作会话只恢复会话树与布局元数据，不创建 Shell 或 Agent 进程；用户首次切换选中某个工作会话时，才实例化其窗格并按相同规则处理。按需实例化只控制首次启动时机：工作会话一旦实例化，切换到其他会话不会暂停或终止其中的 Shell 和 Agent。如果退出前选中的工作会话已归档、已删除或所属工作区不可用，Breath 保持主界面无会话选择且不创建终端，不会自动改选并启动其他会话；工作区不可用时另按移除提示处理。Breath 不在冷启动时批量恢复所有工作会话，也不提供全局恢复并发配置。
