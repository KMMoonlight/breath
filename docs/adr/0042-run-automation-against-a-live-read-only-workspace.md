# 在实时只读工作区中运行自动化

自动化 Agent 直接读取用户绑定的真实工作区，不复制项目，也不保存运行副本。每次运行创建专属临时 HOME 和运行目录，复制必要的 Agent 认证与配置后，以 macOS 进程沙盒启动完整进程树。沙盒允许读取工作区、写入本次临时目录和访问出站网络，但拒绝修改工作区、写入其他用户路径、入站监听、GUI 和交互审批；无法建立沙盒时必须在启动 Agent 前失败。

这个选择让 Agent 看到运行时最新项目内容，同时保证 Breath 不把自动化结果写回项目。运行期间其他程序仍可能改变工作区，因此历史明确标记工作区是实时的，并只记录可解析的起始 Git Commit。临时环境在成功、失败、取消、超时、中断和删除后都必须销毁。

Breath 的外层进程沙盒是自动化运行的唯一权限边界。对于 Codex 等会自行调用 `sandbox-exec` 的 Agent，自动化适配器必须使用其“由外部环境提供沙盒”的无审批模式，否则 macOS 会以 `sandbox_apply: Operation not permitted` 拒绝嵌套沙盒；这不放宽权限，因为 Agent 及其全部子进程仍继承 Breath 的只读工作区策略。
