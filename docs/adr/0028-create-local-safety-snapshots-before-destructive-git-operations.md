# Create local safety snapshots before destructive Git operations

Before Breath performs a Git action that may overwrite or discard local content—such as rollback, checkout, reset, merge, rebase, or stash application—the Git workbench attempts to create a local safety snapshot that can be inspected as a diff and restored by file or selected fragment. Snapshots remain local, are never committed or uploaded, and default to five working days of retention; users may change the duration or set it to zero, while disk pressure may prune cached snapshots earlier. Snapshot creation is best-effort and never blocks a Git operation when unavailable. This provides the recovery role users expect from JetBrains Local History without claiming to continuously capture every filesystem mutation made by terminals, Agents, or external applications.
