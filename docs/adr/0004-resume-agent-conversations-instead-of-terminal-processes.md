# 恢复 Agent 对话而非终端进程

用户执行 `⌘Q` 时，Breath 会二次确认并在确认后结束终端中的进程，但保留工作会话、终端布局以及 Agent 适配器捕获的原生会话标识，不保留终端滚动历史。再次打开 Breath 后，应用只在退出前选中的工作会话中自动启动当时仍在运行的已适配 Agent CLI，并通过其自身的恢复能力续接 Agent 对话；其他工作会话在用户选中时再按同一规则处理。归档恢复只把工作会话移回活跃列表，用户之后选中它时才续接其中此前运行过且具有可用会话标识的 Agent。普通 Shell、恢复失败、未适配或不支持恢复的 CLI 只还原工作会话及终端布局。终端进程本身无需跨应用退出存活，因此不需要让后台终端宿主继续运行。
