# Domain Docs

Breath is a single-context repository.

Before planning or implementing work, read the root `CONTEXT.md` and the relevant decisions under `docs/adr/`. Use the glossary’s canonical vocabulary and avoid the synonyms explicitly listed there. If proposed work contradicts an ADR, surface the conflict instead of silently overriding it.

The consolidated v1 product and architecture design supplements, but does not replace, the glossary and ADRs.
